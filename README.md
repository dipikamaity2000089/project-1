 CareFlow: Clinical Pathway Process Mining

Project Overview

CareFlow analyzes hospital patient-event records to identify workflow delays and repeated activities.

Week 1 Objectives

- Generate mock hospital event logs.
- Identify workflow inefficiencies and loop-backs.
- Prepare event data for analysis.

Planned Event Log Fields

- Case_ID
- Activity_Name
- Timestamp

Technology

- Python
- Git and GitHub
- BigQuery
- dbt
